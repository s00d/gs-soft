# Gateway Soft — Downloads

Gateway Soft is a production modem gateway for SMS, voice, and multi-port orchestration. Use it to run USB and serial modems as a managed farm with a single operator UI.

## Builds in each release

Every `v*` tag ships artifacts for the channels you need:

- **Headless gateway** — server installers and portable bundles (Linux, macOS, Windows).
- **Desktop app** — native shell with tray and auto-updates.
- **Android APK** — mobile ops build.

Open the latest release, download the file for your OS and architecture, and follow the short guide on the [landing downloads section](https://s00d.github.io/gs-soft/#downloads).

## Updates

Headless and desktop builds check this repository for newer `v*` releases and update automatically when configured. See release notes on each tag for changes.
